Official portfolio website for **Aadya Baiswar**, competitive rifle shooter competing in **10m Air Rifle**, **50m Rifle Prone**, and **50m Rifle Three Positions (3P)**.

## Overview
- **Disciplines**: 10m Air Rifle · 50m Rifle Prone · 50m Rifle 3P
- **Equipment**: Walther LG400 Match Air Rifle & .22 Match Rifle
- **Major Honors**: 
  - Back-to-back Renowned Shooter recognition at the National Shooting Championship (NSCC 2023 & 2024)
  - Two Champions of Champions (CoC) Trophies
  - International invitation and selection for IRS-Cup Belgium 2023
  - 15+ podium finishes across State and All India championships

## Features
- **Hero Showcase**: Featuring Aadya's authentic Walther LG400 precision competition rifle.
- **About**: Biography, marksmanship ethos, and technical rifle specifications.
- **Achievements**: Interactive Bento Grid showcasing 8 official physical framed medals, modal inspector, and full 12-event Competition Ledger.
- **Career Journey**: Four-year progression timeline from debut season (2022) to international selection and state gold (2026).
- **On the Range Gallery**: High-resolution range and competition photography with distraction-free fullscreen viewer.
- **Contact**: Direct email (`aadyabaiswar@gmail.com`) and Instagram (`@its_aadya_baiswar`) links.

## Tech Stack
- **Framework**: [React 19](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Styling**: Vanilla CSS Design System (Sora + IBM Plex Sans typography)
- **Deployment**: Optimized for [Vercel](https://vercel.com/)

## Local Development

```bash
# Clone the repository
git clone <your-repo-url>
cd "Athelete Portfolio"

# Install dependencies
npm install

# Start local dev server
npm run dev

# Build for production
npm run build

# Preview production build locally
npm run preview
```

## Deploying to Vercel

1. Push this repository to your **GitHub** account.
2. Go to [Vercel Dashboard](https://vercel.com/dashboard) and click **"Add New Project"**.
3. Select your GitHub repository and click **"Import"**.
4. Vercel automatically detects the Vite framework settings:
   - **Framework Preset**: `Vite`
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
5. Click **"Deploy"**. Your portfolio will be live in seconds!
